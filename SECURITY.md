# Security

Report security issues privately through GitHub's **Security → Report a vulnerability** when the repository has private vulnerability reporting enabled. Otherwise, open a public issue asking maintainers for a private reporting channel and omit the vulnerability details.

Use the latest published release. Verify its checksum before installing. During testing, share only the device model, firmware, app version, and relevant redacted behavior. Remove keys, tokens, account information, and device addresses from attachments.

The signed release is produced locally. CI builds unsigned release and separately signed development artifacts.
